# Python Agent 安全边界

## 默认保证

- `local` 模式只允许绑定 `127.0.0.1`、`::1` 或 `localhost`。只有显式设为 `hosted` 时才能绑定 `0.0.0.0` 或 `::`，且必须同时提供 HTTPS 公开 Origin 和至少 32 字符的站点口令。
- GitHub Pages 只托管静态文件；仓库和发布产物均不包含 API Key。
- API Key 只从被 Git 忽略的 `.env` 或托管平台加密环境读取，保存在服务进程与受控子进程内存中；它不会发送给浏览器，也不写入 localStorage、日志、provider 摘要或发布产物。
- 托管模式的独立站点口令只在登录 POST 中传输一次，服务不回显、不记录它；成功后使用 HMAC 签名的 12 小时 HttpOnly、Secure、SameSite=Strict Cookie。
- 托管模式对 Host 和写入请求 Origin 做精确校验，不开放 CORS；未鉴权请求不能进入分析、停止或重置 API。
- Codex 线程使用 `read-only` 沙箱、拒绝全部审批、禁用 Web Search，并显式清空 MCP server 配置。模型网络请求只发往启动配置中的 provider。
- 子进程不继承完整环境，只收到运行所需的系统路径变量，以及自定义 provider 请求所需的临时 Key。
- 生成结果中的知识节点必须来自本轮检索白名单；展示的关系必须存在于冻结图谱中。
- 请求体限制为 1 MB，问题限制为 4–4,000 字符，同时最多运行两个分析；会话只保存在内存中并定期过期。
- 静态响应启用 CSP、`nosniff`、Referrer Policy 和 Permissions Policy；托管模式额外启用 HSTS。

## 仍需由使用者承担的边界

- 提交给模型的问题和对话会发送到你选择的模型服务，请遵守该服务的隐私与数据政策。不要输入不必要的机密、凭据或个人敏感信息。
- 本项目提供问题结构化和决策支持，不替代医疗、法律、财务、安全等领域的合格专业人员。高风险或不可逆情境必须提高证据、授权、监督和升级门槛。
- 本地模式中，同一台计算机上的其他进程仍可能连接回环端口。不要在不可信的共享主机上输入密钥。
- 在线模式会消耗模型账户额度。站点口令应与模型 Key 分离、通过可靠渠道传递并定期轮换；发现异常用量时应立即停止服务并轮换两个密钥。
- `.env` 是本机秘密文件：应限制文件访问权限、定期轮换 Key，并确保它始终保持未跟踪状态。修改配置后需要重启服务。

## 威胁模型中的关键取舍

Agent 让模型看到的是当前问题、有限对话摘要和检索子图，而不是整套用户环境。Codex runtime 仍然是受控子进程，因此采用只读沙箱、最小环境、专用临时目录、无 Web Search 和无 MCP 的组合防线；仅保留调用所配置模型服务所需的网络能力。在线容器是公网服务，虽有强口令、同源检查和并发上限，仍应由托管平台持续监控资源与用量。若未来增加文件上传、外部检索或写入工具，必须重新审计权限、数据保留、认证、速率限制与调用配额。
