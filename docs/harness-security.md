# Python Agent 安全边界

## 默认保证

- 服务只允许绑定 `127.0.0.1`、`::1` 或 `localhost`，拒绝公网监听。
- GitHub Pages 只托管静态文件；仓库和发布产物均不包含 API Key。
- API Key 只从被 Git 忽略的 `.env` 或外部进程环境读取，保存在服务进程与受控子进程内存中；它不会发送给浏览器，也不写入 localStorage、日志、provider 摘要或发布产物。
- Codex 线程使用 `read-only` 沙箱、拒绝全部审批、禁用 Web Search，并显式清空 MCP server 配置。模型网络请求只发往启动配置中的 provider。
- 子进程不继承完整环境，只收到运行所需的系统路径变量，以及自定义 provider 请求所需的临时 Key。
- 生成结果中的知识节点必须来自本轮检索白名单；展示的关系必须存在于冻结图谱中。
- 请求体限制为 1 MB，问题限制为 4–4,000 字符，同时最多运行两个分析；会话只保存在内存中并定期过期。
- 静态响应启用 CSP、`nosniff` 和 Referrer Policy。

## 仍需由使用者承担的边界

- 提交给模型的问题和对话会发送到你选择的模型服务，请遵守该服务的隐私与数据政策。不要输入不必要的机密、凭据或个人敏感信息。
- 本项目提供问题结构化和决策支持，不替代医疗、法律、财务、安全等领域的合格专业人员。高风险或不可逆情境必须提高证据、授权、监督和升级门槛。
- 绑定回环地址可避免一般网络访问，但同一台计算机上的其他本地进程仍可能连接该端口。不要在不可信的共享主机上输入密钥。
- `.env` 是本机秘密文件：应限制文件访问权限、定期轮换 Key，并确保它始终保持未跟踪状态。修改配置后需要重启服务。

## 威胁模型中的关键取舍

Agent 让模型看到的是当前问题、有限对话摘要和检索子图，而不是整套用户环境。Codex runtime 仍然是本机子进程，因此采用只读沙箱、受控环境、专用工作目录、无 Web Search 和无 MCP 的组合防线；仅保留调用所配置模型服务所需的网络能力。若未来增加文件上传、外部检索、写入工具或远程托管，必须单独做权限、数据保留、CSRF/CORS、认证、速率限制和审计设计；当前安全保证不自动覆盖这些扩展。
