# 多维思考框架 / Multi-dimensional Thinking Framework

> 本文件由 `08-data/frameworks.yaml` 生成。请修改数据源后运行 `python scripts/generate_views.py`。
> 版本：v0.7.0 · 节点：`hkm:framework:multidimensional-thinking`

用十个互补透镜检查问题的框定、证据、机制、系统、主体、资源、时间、网络、意义和行动风险，避免把单一学科或单一模型误作完整现实。

## 进入框架前

1. 我正在解释、预测、评价、设计还是决定什么
2. 哪些后果不可接受且何时必须升级
3. 哪些透镜对当前问题最关键而哪些可以明确暂缓

## 使用方式

先用十个透镜做宽扫描，再按问题风险和信息价值选择 3–6 个透镜深入。每个被暂缓的透镜都要留下理由；发现高风险、不可逆性、权利冲突或关键未知时，转入通用问题求解框架并提高流程深度。

## 逐项调用

### 1. 框定、目的与边界 / Framing Purpose and Boundaries

明确问题陈述、成功标准、价值、非目标、模型边界和受影响者。

**检查问题**

- 真正要改变或理解的对象是什么
- 谁定义成功且谁承担代价
- 哪些内容在边界外但可能改变结论

**领域入口：** D01 元知识、哲学与探究 / D20 日常生活、实践技能与自我管理

**Thinking Models：** TM29 地图不等于领土与模型边界 / TM40 视角转换、语境化与反思性解释

**Universal Models：** UM22 主体、激励与治理 / UM17 风险、不确定性与可选性

**退出产物：** 一页问题契约，含目标、非目标、边界、受影响者和升级阈值。

### 2. 证据、测量与未知 / Evidence Measurement and Unknowns

追踪数据如何产生，区分观察、推断、价值和未知，并校准证据权重。

**检查问题**

- 当前状态如何被测量且误差来自哪里
- 基准率和竞争证据是什么
- 哪些未知可学习哪些只能用情景管理

**领域入口：** D02 数学、统计与形式系统 / D12 计算、信息与人工智能 / D14 健康、医学与福祉

**Thinking Models：** TM03 概率思维与分布判断 / TM04 贝叶斯更新与证据权重 / TM22 选择偏差与幸存者偏差 / TM30 基准率与参考类预测

**Universal Models：** UM21 测量、观察与推断 / UM06 信息、信号与表征

**退出产物：** 证据账本，含来源、测量链、可信区间、缺失数据和更新条件。

### 3. 因果、机制与替代解释 / Causality Mechanisms and Alternatives

从相关性走向可检验机制，同时保留多层原因和竞争解释。

**检查问题**

- 必要与促成机制分别是什么
- 有哪些反事实和共同原因
- 微观机制如何产生宏观表现

**领域入口：** D03 物质、能量与宇宙 / D05 生命与进化 / D06 心智、脑与行为

**Thinking Models：** TM01 第一性原理与基本约束分解 / TM02 因果与机制推理 / TM19 涌现与多层解释

**Universal Models：** UM01 存量、流量与守恒 / UM04 变异、选择与适应 / UM14 涌现、多尺度与组织

**退出产物：** 因果图与竞争解释表，列出可区分预测和潜在反证。

### 4. 系统、动力学与韧性 / Systems Dynamics and Resilience

检查存量流量、反馈、延迟、约束、阈值、级联和恢复能力。

**检查问题**

- 核心状态变量和反馈回路是什么
- 瓶颈阈值与延迟在哪里
- 局部优化会怎样破坏整体韧性

**领域入口：** D04 地球、空间与环境 / D13 工程、技术与设计 / D17 安全、冲突与韧性

**Thinking Models：** TM05 系统思维与边界建模 / TM06 反馈回路与控制思维 / TM20 临界阈值与突变 / TM24 约束理论与瓶颈 / TM38 模块化、接口与松耦合

**Universal Models：** UM02 反馈、调节与控制 / UM07 约束、瓶颈与可行性 / UM09 能量、功与效率 / UM10 熵、耗散与维护 / UM12 周期、振荡与延迟 / UM13 非线性、阈值与状态转换 / UM15 层级、模块化与接口 / UM20 韧性、冗余与恢复

**退出产物：** 动态系统图、失效路径、控制点和恢复方案。

### 5. 主体、激励与制度 / Agents Incentives and Institutions

识别权力、信息、策略互动、正式规则与非正式规范如何改变行为。

**检查问题**

- 各主体想要什么且掌握什么信息
- 规则会诱发哪些策略反应
- 谁拥有决定权申诉权和退出权

**领域入口：** D07 社会、人类与群体 / D09 政治、治理与法律 / D10 经济、金融与组织

**Thinking Models：** TM10 激励与机制设计 / TM11 策略互动与博弈论 / TM32 委托代理与信息不对称 / TM33 集体行动与公地治理

**Universal Models：** UM05 竞争、合作与协调 / UM22 主体、激励与治理

**退出产物：** 主体—激励—权力图及可预期策略响应。

### 6. 资源、选项与权衡 / Resources Options and Trade-offs

把稀缺、机会成本、可行集、可选性和分配后果放入同一决策空间。

**检查问题**

- 真正稀缺的资源和硬约束是什么
- 包括不行动在内有哪些可行选项
- 效率风险公平与可逆性如何权衡

**领域入口：** D10 经济、金融与组织 / D13 工程、技术与设计 / D15 农业、食物与生物生产

**Thinking Models：** TM08 边际分析 / TM09 机会成本 / TM26 可选性与实物期权 / TM37 权衡与可行前沿

**Universal Models：** UM08 资源配置、权衡与机会成本 / UM18 优化、搜索与学习

**退出产物：** 可行选项集、机会成本和多准则权衡前沿。

### 7. 时间、尺度与历史路径 / Time Scale and Historical Path

比较短长期、微观宏观和不同历史路径，识别累积、锁定与不可逆变化。

**检查问题**

- 结论随时间窗和尺度怎样改变
- 哪些早期选择形成锁定
- 历史类比在哪些机制上相似又在哪里失效

**领域入口：** D08 历史、考古与文明 / D18 艺术、文学与创造 / D19 宗教、意义与世界观

**Thinking Models：** TM07 二阶效应与后果链 / TM14 复利、累积与再投资 / TM16 规模效应与尺度转换 / TM21 路径依赖与锁定 / TM40 视角转换、语境化与反思性解释

**Universal Models：** UM11 增长、衰减与饱和 / UM16 复制、传播与记忆 / UM19 路径依赖、递增收益与锁定

**退出产物：** 多时间尺度后果链、历史路径和不可逆点清单。

### 8. 网络、分布与接口 / Networks Distributions and Interfaces

检查连接结构、传播、集中度、厚尾、专业化和接口失效。

**检查问题**

- 谁与谁连接且什么会沿网络传播
- 平均值掩盖了哪些分布和尾部风险
- 模块边界与接口如何改变扩散和故障

**领域入口：** D07 社会、人类与群体 / D11 语言、传播与媒体 / D12 计算、信息与人工智能

**Thinking Models：** TM17 网络效应与连接价值 / TM18 幂律、厚尾与长尾 / TM25 帕累托式集中与优先级 / TM31 比较优势、专业化与交换 / TM38 模块化、接口与松耦合

**Universal Models：** UM03 网络、连接与传播 / UM15 层级、模块化与接口

**退出产物：** 网络与接口图、分布摘要、传播和级联路径。

### 9. 学习、语言与意义 / Learning Language and Meaning

评估人的认知、动机、语言、文化、创造和价值解释如何影响问题与方案。

**检查问题**

- 人们如何理解记忆和学习这件事
- 语言和媒介怎样框定可见选项
- 哪些权利身份传统和意义不能被单一效用指标替代

**领域入口：** D06 心智、脑与行为 / D11 语言、传播与媒体 / D16 教育、学习与发展 / D18 艺术、文学与创造 / D19 宗教、意义与世界观

**Thinking Models：** TM12 变异、选择与进化思维 / TM34 实验、迭代与可学习行动 / TM40 视角转换、语境化与反思性解释 / TM41 发散、收敛与创造性迭代

**Universal Models：** UM04 变异、选择与适应 / UM16 复制、传播与记忆 / UM18 优化、搜索与学习

**退出产物：** 认知与语境假设、受众解释和不可化约价值清单。

### 10. 风险、行动与反证 / Risk Action and Disconfirmation

在深度不确定性下设计可逆行动、保护性冗余、监测和明确的停止升级条件。

**检查问题**

- 最坏的可信后果和共同原因失效是什么
- 能否先做可逆且可学习的小步试验
- 什么观测会推翻方案并触发停止求助或升级

**领域入口：** D14 健康、医学与福祉 / D17 安全、冲突与韧性 / D20 日常生活、实践技能与自我管理

**Thinking Models：** TM23 逆向思考与失败预演 / TM27 冗余、缓冲与安全余量 / TM28 稳健性、韧性与反脆弱 / TM35 情景、敏感性与稳健决策 / TM36 可逆与不可逆决策

**Universal Models：** UM17 风险、不确定性与可选性 / UM20 韧性、冗余与恢复 / UM21 测量、观察与推断

**退出产物：** 风险登记、试验协议、监测指标、停止和专业升级条件。

## 质量门

- 问题与成功标准能被不同参与者复述
- 事实推断价值和未知被明确分开
- 至少保留一个竞争解释和一个不行动选项
- 检查短长期分配与二阶效应
- 高风险行动已有权限监督和升级接口

## 完整输出

- 问题契约
- 证据账本
- 竞争解释与系统图
- 主体激励和权衡分析
- 风险行动与反证协议

## 停止与升级

- 出现生命健康安全或法律紧急风险
- 关键证据质量不足且行动不可逆
- 决策超出授权或影响未被代表群体
- 结果对模型边界或价值权重高度敏感

## 边界

十个透镜是检查清单而不是要求平均用力；低风险问题可压缩，但不得省略安全升级、证据边界或受影响者。透镜发现问题，不替代领域专业知识。
