# 跨学科模型层设计

> 版本：v0.4.0（冻结）  
> 范围：Thinking Models 与 Universal Models

阶段 4 在 20 域骨架之上增加两种不同但互联的模型。二者都不是术语清单，也不替代领域证据。

## 1. 两层分工

| 层 | 回答的问题 | 最小证据 |
|---|---|---|
| Thinking Model | 人在分析、判断或设计时可以调用什么可迁移推理工具？ | 来源领域、底层机制、适用问题、案例、反例、边界、误用与模型关系 |
| Universal Model | 哪些结构和动力学在多个现实领域反复出现？ | 状态变量、动力学、至少四个 H2 的表现、失效模式、边界与相关模型 |

Thinking Model 是**认知操作**，例如贝叶斯更新、逆向思考和安全边际；Universal Model 是**世界结构**，例如存量—流量、反馈控制和变异—选择—适应。一个思维模型可以调用多个通用模型，一个通用模型也可以由多种推理工具观察和操作。

## 2. 身份与关系

- Thinking Model 使用 `hkm:thinking-model:*` 稳定 ID，代码为 `TMxx`。
- Universal Model 使用 `hkm:universal-model:*` 稳定 ID，代码为 `UMxx`。
- `source_domains` 表示历史与方法来源，不是唯一所有权。
- `mechanism_core_nodes` 与 `manifestations[].core_nodes` 把跨学科模型锚定到 v0.3.0 的领域骨架。
- `related_models` 只允许 Ontology 已定义的类型化关系；相似不等于同一。
- 生成关系使用 `derived-from`、`applies-to`、`explains`、`complements`、`depends-on` 等类型进入总图。

## 3. 质量门槛

1. 每个思维模型至少来自两个 H2，并连接至少两个领域核心节点。
2. 每个通用模型至少在四个 H2、三个 H1 超级领域中给出具体表现。
3. 案例必须展示模型真正有用的情形；反例必须展示模型不适用或会误导的情形。
4. 每个模型必须写清边界与常见误用，不把启发式包装为定律。
5. 中英文标签、代码、ID 不重复；所有引用目标存在；生成视图与关系必须可复现。
6. 高迁移不等于高精度：领域模型、测量、资格、伦理和地方情境始终优先。

## 4. 冻结条件

阶段 4 已达到冻结条件：41 个 Thinking Models 覆盖推理、因果、概率、系统、决策、组织、风险、设计、解释、创造与学习等主要操作；22 个 Universal Models 均跨至少四个 H2、三个 H1，并通过引用、重复、覆盖和站点交互审计。后续 Problem → Knowledge Mapping 以本版本为稳定模型词表；新增模型必须先证明其不可由现有模型组合表达。
