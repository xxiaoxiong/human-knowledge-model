# H3 结构压力测试

> 对象：D03、D10、D13、D20；版本：v0.2-draft；目的：判断 H2 是否应拆分、合并或转为桥接视图。

## 1. 判据与决策规则

压力测试不用“已有多少院系”作为唯一依据，而同时检查六项：

| 判据 | 核心问题 | 拆分信号 |
|---|---|---|
| 核心问题凝聚性 | H3 是否仍回答可复述的共同问题？ | 必须用互不相干的两套问题解释父域 |
| 内部联系密度 | H3 间是否共享机制、变量和依赖？ | 跨候选簇关系长期少于簇内关系且无关键桥 |
| 方法与证据重叠 | 是否共享实验、建模、测量或实践传统？ | 证据标准和方法几乎不相通 |
| 导航收益 | 拆分是否显著降低定位成本？ | 用户反复先区分两类父域才能检索 |
| 问题路由影响 | 现实问题是否常需同时调用两个候选簇？ | 同时调用罕见，拆分不会切断行动链 |
| 演化成本 | 新边界能否稳定承受新增节点？ | 名称、交叉归属和父子迁移成本持续过高 |

决策采用保守重构：只有至少四项出现强拆分信号，且没有不可替代的共同核心，才在 H2 层拆分。否则保留 H2，以内部簇、桥接视图或分面解决导航问题。进入阶段 3 后，如果任一内部簇超过 20 个核心骨架节点、跨簇依赖少于全部依赖的 20%，或 30% 以上节点出现主归属争议，则重新评估。

## 2. D03 物质、能量与宇宙

**候选拆分：** 物理与天文学 / 化学与材料基础。

| 检查 | 观察 |
|---|---|
| 共同核心 | 都研究物质、能量、相互作用、结构与变化，尺度从粒子到宇宙。 |
| 关键内联 | 量子与分子结构连接化学；热力学连接相变和反应；光谱与测量连接天文、物理和分析化学；凝聚态连接材料化学。 |
| 导航问题 | “化学”作为名称需要更高可见性，但已由 D03.09–D03.12 连续呈现。 |
| 拆分代价 | 会把热力学、量子、材料性质和光谱测量切成大量跨父边，并重复“基础材料”边界。 |

**决定：保留 D03。** 以“物理与宇宙”“化学与分子/材料基础”作为内部导航簇；另建“材料科学”桥接视图连接 D03、D04、D05、D13。若阶段 3 中两个簇各自形成独立且低互联的超大骨架，再考虑拆分。

## 3. D10 经济、金融与组织

**候选拆分：** 经济与金融 / 组织与经营。

| 检查 | 观察 |
|---|---|
| 共同核心 | 都研究稀缺资源、激励、信息、不确定性和协调机制；市场与组织是两类相互替代又互补的治理结构。 |
| 内部簇 | D10.01–D10.08 偏经济—金融；D10.09–D10.14 偏组织—经营。 |
| 关键内联 | 公司金融与治理、产业组织与战略、劳动经济与人力、信息经济与运营、风险与审计跨越两簇。 |
| 拆分收益 | 能降低院系式导航的认知成本，但会迫使大量现实问题先做并不稳定的“市场还是组织”选择。 |
| 边界风险 | 广义组织社会学归 D07，公共制度归 D09，生产技术归 D13；拆出“组织”并不能消除这些桥接。 |

**决定：保留 D10，显式维护双簇。** 阶段 3 分别生成“经济—金融机制骨架”和“组织—经营行动骨架”，共享激励、信息、交易成本、治理、风险和绩效节点。若两簇均超过 20 个核心节点且跨簇依赖低于 20%，优先拆为两个 H2，而不是无限扩张 D10。

## 4. D13 工程、技术与设计

**候选拆分：** 工程学科 / 跨领域设计与全生命周期实践。

| 检查 | 观察 |
|---|---|
| 共同核心 | 所有 H3 都将需求转成在物理、成本、人因、安全和环境约束下可运行的人造系统。 |
| 方法重叠 | 需求分析、建模、权衡、原型、验证、制造、运行、维护和失效分析贯穿各工程门类。 |
| 内部簇 | D13.02–D13.12 偏对象/行业工程；D13.01、D13.13、D13.14 提供系统、设计与生命周期横轴。 |
| 拆分代价 | 把系统工程、可靠性和设计独立成父域会使其失去所作用的对象，同时诱发与 D12、D18 的边界重复。 |

**决定：保留 D13。** 阶段 3 必须以“需求—架构—实现—验证—运行—维护—退役”为横向生命周期，而不是只列工程专业；材料科学、城市系统和人机交互由桥接视图补足。

## 5. D20 日常生活、实践技能与自我管理

**候选处理：** 删除为杂项 / 把内容分回专业领域 / 保留为实践整合域。

| 检查 | 观察 |
|---|---|
| 共同核心 | 专业知识如何转成个人与家庭可执行、可练习、可判断风险的行动能力。 |
| 独特认识方式 | 具身技能、情境判断、维护、照护、习惯和求助阈值不能被“知道命题”替代。 |
| 覆盖价值 | 家务、维修、个人财务、数字素养、关系、运动与应急在正式学科分类中经常系统性缺席。 |
| 主要风险 | 若无准入规则，会吸收一切“有用知识”，成为无法维护的杂项桶。 |

**决定：保留 D20，但实行四项准入。** 新 H3 或骨架节点必须同时满足：

1. 对个人、家庭或社区具有高频或高风险的直接行动价值；
2. 需要跨专业知识的情境整合，而非只是某专业领域的简化摘要；
3. 能定义可观察技能、练习、检查表或决策阈值；
4. 明示安全边界、常见失效方式以及何时应求助专业人员。

不满足四项者回到对象领域，并用学习路径或 `applies-to` 连接生活场景。D20 不提供无资质医疗、法律、工程或投资处方。

## 6. 结论与冻结条件

四个 H2 均未达到立即拆分的四项强信号。v0.2 的 H2/H3 结构可进入桥接和审计，但冻结必须满足：

- D03、D10、D13 的内部簇在生成视图中可见；
- 至少覆盖地理、认知科学、复杂系统、气候与可持续性、公共卫生、材料、信息、数据与因果、城市、科学技术与社会十个桥接视图；
- D20 的实践准入和专业求助边界进入后续骨架模板；
- 机器校验能发现桥接成员失效、跨文化/实践哨兵缺失和生成文件过期。
